# あたまおしりゲーム

指定された「頭の文字」から始まり、「おしりの文字」で終わる、できるだけ長い日本語を考えるブラウザゲームです。

## 遊び方

1. 「60秒スタート」を押す
2. 画面の「○ → ○」に合う言葉を入力
3. 「判定する」を押す
4. 文字数の長い順にランキング
5. 「別のお題」で次の組み合わせへ

### 例
- や → り：やきとり
- ら → ん：らーめん

## 仕様
- スマホ対応
- ひらがな／カタカナを同じ文字として判定
- 入力履歴と最高記録を端末内（localStorage）に保存
- 外部ライブラリ不要
- `index.html` 単体で動作

## 起動
`atama-oshiri-game/index.html` をブラウザで開くだけで遊べます。
