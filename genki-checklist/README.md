# 健康カプセル！ゲンキの時間　セルフチェック一覧

CBCテレビ「健康カプセル！ゲンキの時間」の番組公式アーカイブ（https://hicbc.com/tv/genki/archive/ ）で紹介されたセルフチェックをまとめたものです。

> **注意**
> - 公式サイトに自動でアクセスできなかったため、検索結果の抜粋をもとに作りました。
> - 項目の言い回しは番組の原文と同じではありません。正確な内容は各回の公式ページで確認してください。
> - セルフチェックは目安です。診断ではありません。気になる症状がある場合は医療機関に相談してください。

## ① 内容まで確認できたもの

### 隠れ脂肪肝チェック
2020/12/20放送「侮れない！脂肪肝の恐怖」
— 3つ以上当てはまると脂肪肝の可能性あり
（[公式ページ](https://hicbc.com/tv/genki/archive/201220/)）

- [ ] 週に3日以上お酒を飲む
- [ ] 通勤や買い物はほとんど車
- [ ] 20歳の頃より体重が10kg以上増えた
- [ ] ジュースなど甘い飲み物をよく飲む
- [ ] 寝る前2時間以内に食べることがある
- [ ] 睡眠時間が平均6時間未満

### 超簡単！歯周病セルフチェック
2019/6/2放送 — 5項目、3つ以上当てはまると歯周病の可能性あり
（[公式ページ](https://hicbc.com/tv/genki/archive/190602/)）
※ わかったのは各項目のテーマだけです

- [ ] 歯ぐきの色
- [ ] 歯の表面のザラつき
- [ ] 歯みがきのときの出血
- [ ] 朝の口のネバつき
- [ ] 歯に食べ物がはさまる

### 毛細血管チェック
2017/6/18放送（[公式ページ](https://hicbc.com/tv/genki/archive/170618/)）

- [ ] 爪の根元を5秒押して離し、赤みが戻るまでの秒数を数える（約2秒が目安）

### 逆流性食道炎チェック
2013/3/24放送「食道」 — 1つでも当てはまれば疑いあり
（[公式ページ](https://hicbc.com/tv/genki/archive/130324/)）

- [ ] 軽い胸やけが週に2日以上ある、またはつらい胸やけが週に1回以上ある
- [ ] 胃からすっぱい液が上がってくることがある
- [ ] 寝ているときに咳で目が覚めることがある
- [ ] 太り気味である

### ピロリ菌 感染度チェック
2013/5/19放送「ピロリ菌」 — 3つ以上で感染の可能性が高まる
（[公式ページ](https://hicbc.com/tv/genki/archive/130519/)）

- [ ] 子どもの頃、川で遊んだり井戸水を飲んだりしていた
- [ ] 親が食べ物をかみ砕いて食べさせてくれていた
- [ ] 親が胃の病気をしたことがある
- [ ] 若い頃はよく胃が痛かったが、今は痛くない
- [ ] 健康診断で胃炎と言われたことがある

### 足裏アーチ崩壊 危険度チェック
2012/6/10放送「足裏」 — 1つでも当てはまればアーチが崩れている可能性あり
（[公式ページ](https://hicbc.com/tv/genki/archive/120610/)）

- [ ] 外反母趾がある
- [ ] 人差し指の付け根にタコがある
- [ ] 大きめの靴を履いている
- [ ] 足の幅が広いと感じる
- [ ] 足が疲れやすい
- [ ] 偏平足である

### 汗腺の衰えチェック
2013/7/21放送「熱中症～後編～」 — 3つ以上で汗腺が衰えている可能性あり
（[公式ページ](https://hicbc.com/tv/genki/archive/130721/)）
※ 検索結果で確認できたのは4項目です。番組ではもっと多い可能性があります

- [ ] 冷房の効いた部屋にいる時間が長い
- [ ] ほとんど運動をしない
- [ ] 湯船につからず、シャワーですませることが多い
- [ ] 体の一部だけに大量の汗をかく

### 脳の疲れチェック
2016/7/17放送「疲れない脳」 — 1つでも当てはまれば脳が疲れている可能性あり
（[公式ページ](https://hicbc.com/tv/genki/archive/160717/)）

- [ ] 夜遅くまでスマホでSNSやニュースを見ている
- [ ] 寝る前にお酒を飲む
- [ ] 30分以上座りっぱなしでいることが多い
- [ ] のどが渇くまで水を飲まない
- [ ] 起きる時間が決まっていない
- [ ] 寝る直前までスマホを見ている
