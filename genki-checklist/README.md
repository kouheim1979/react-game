> **注意**
> - 公式サイトに自動でアクセスできなかったため、検索結果の抜粋をもとに作りました。
> - 項目の言い回しは番組の原文と同じではありません。正確な内容は各回の公式ページで確認してください。
> - セルフチェックは目安です。診断ではありません。気になる症状がある場合は医療機関に相談してください。

## ① 内容まで確認できたもの

### 隠れ脂肪肝チェック
2020/12/20放送「侮れない！脂肪肝の恐怖」
— 3つ以上当てはまると脂肪肝の可能性あり
（[公式ページ](https://hicbc.com/tv/genki/archive/201220/)）

- [ ] 週に3日以上お酒を飲む
- [ ] 通勤や買い物はほとんど車
- [ ] 20歳の頃より体重が10kg以上増えた
- [ ] ジュースなど甘い飲み物をよく飲む
- [ ] 寝る前2時間以内に食べることがある
- [ ] 睡眠時間が平均6時間未満

### 超簡単！歯周病セルフチェック
2019/6/2放送 — 5項目、3つ以上当てはまると歯周病の可能性あり
（[公式ページ](https://hicbc.com/tv/genki/archive/190602/)）
※ わかったのは各項目のテーマだけです

- [ ] 歯ぐきの色
- [ ] 歯の表面のザラつき
- [ ] 歯みがきのときの出血
- [ ] 朝の口のネバつき
- [ ] 歯に食べ物がはさまる

### 毛細血管チェック
2017/6/18放送（[公式ページ](https://hicbc.com/tv/genki/archive/170618/)）

- [ ] 爪の根元を5秒押して離し、赤みが戻るまでの秒数を数える（約2秒が目安）
